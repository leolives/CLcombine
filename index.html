Conditional pattern scanner

Upload 15-minute OHLC bars as CSV (columns: date,time,open,high,low,close — time as HH:MM in one consistent timezone, 24hr). For each time-of-day slot, this computes P(next candle up | prior candle was up) and P(next candle up | prior candle was down), tests each against a 50% baseline, and applies a Bonferroni correction for the number of slots tested — so it won't lie to you about how many "patterns" are just chance. Get historical CL bars from your broker's export, TradingView, or CME DataMine; this tool can't fetch them itself.

CL position size, stop & target

Standard CL (1,000 bbl contract): tick 0.01 = $10. Micro MCL (100 bbl): tick 0.01 = $1 — switch the two fields above if you're trading MCL. Re-check against your platform periodically; exchange specs can change.

Is this pattern real, or could it be chance?

This only answers "is this distinguishable from chance." It does not check for multiple-comparison bias (did you test many windows and pick the best one?) or confirm a real mechanism — both matter as much as the math. And this checks your discovery sample; the real test is whether the rate holds on data collected after you found the pattern.
